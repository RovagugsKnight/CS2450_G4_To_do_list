# User Stories

2. As a goal oriented user, I want a checkbox to complete a task, so that I can know what I have done and what I still have to do.

3. As a focused worker, I want to prioritze tasks as High, Medium, or Low priority, so that I know which tasks I should focus on first with limited time. 
- 6
4. As a planner, I want to be able to add and see any upcoming deadlines, so that I can plan my schedule around my to-do list. 
- 5
5. As a organizer, I want to be able to put my taks into categories, so that I can seperate my work, school, and home lists.
