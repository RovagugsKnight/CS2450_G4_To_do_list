User Stories
============================================================================
1. As a user I want to easily categorize my priority list I must do = 
2. As a user I want to easily give priority to my list per week and per day.
3. As a user I want to easily remove added mistaken things from my list.
4. As a user I want to see a history of what I have done, day and time.
5. As a user I want to implement reminders of what is coming.
