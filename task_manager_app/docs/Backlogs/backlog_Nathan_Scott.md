## User Stories
1. As a student I want to add/remove my tasks so that I can keep track of what needs to be done.   
- 5 pts
2. As a Busy Person I want to be able to mark tasks as complete so I can move to the next one.    
- 3pts
3. As a person I want to be able to change the priority of tasks so I can complete the biggest ones first.  
- 5pts
4. As a gamer I want to add an "experience system", so that I'm motivated to comlete the tasks   
- 8pts
5. As a person I want to be able to customize the colors so I can personalize the list.    
- 6pts
