# Task Manager Validation

## Add Task
__Input__: input "my task" into text box and clicked add. (+) button

__Output__: card with "my task" appears on screen.

## Delete Task
__Input__: clicked Delete, (-) button, next to card

__Output__: that card dissapears

## Edit Task
__Input__: clicked edit next to "my task" card

__Output__: textbox popup appears with "my task" inside

__Input__: rewrote to "next task" and pressed save

__Output__: "my task" card now appears as "next task"

## ADD Without Input
__Input__: clicked add without giving input

__Output__: Popup appears that says "Task cannot be empty."

## ADD With too many Characters
__Input__: clicked add with over 150 characters

__Output__: popup appears that says "Task is too long. Maximum length is 150 characters."

## Mark Task Done
__Input__: clicked Done next to card

__Output__: Done button turns black
