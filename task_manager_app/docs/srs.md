## 1. Introduction

### 1.1 Document Purpose
This is the document for explaining system requirments
not for how it will be implemented. This App can
be used for managing tasks for personal use.

### 1.2 Scope
The Task Manager will be used for managing personal tasks
and so a user can be organized and stay on track for personal
goals. It will allow for logging and setting reminders for tasks
and setting up a schedule for accomplishing them. It will give the
user a better way manage and acccomplish their goals.

__UI__: User Interface for user to interact with app.
